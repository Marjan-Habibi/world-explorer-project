# World Explorer

World Explorer is a Next.js project that allows users to explore countries around the world using real API data.

## Features

* App Router
* File-based routing
* Shared layout
* Dynamic routes
* Server components
* Client components
* Real API data fetching
* Static rendering and caching
* Dynamic rendering
* Search functionality
* Responsive design

## Pages

* Home Page
* Countries Page
* Country Details Page
* Search Page
* About Page

## Components

* Navbar
* Footer
* CountryCard
* CountrySearch

## API Used

REST Countries API

https://restcountries.com/v3.1/all

## Technologies Used

* Next.js
* React
* CSS

## Run Locally

```bash
npm install
npm run dev
```
